# まんが日記 UI Implementation Handoff — monochrome v2

このフォルダは **既存の React/Vite/TypeScript/PWA プロジェクトに UI を実装するための視覚仕様・状態別仕様** です。デザインを「SVGで丸ごと貼り付ける」のではなく、意味のある HTML / React 部品として再構築してください。

## まず読むファイル

1. `IMPLEMENTATION_PROMPT.md` — Codex / Claude Code に最初に渡す命令文（そのまま貼り付け可）
2. `DESIGN_SPEC.md` — 色、寸法、画面レイアウト、ナビ、表示ルールの基準
3. `screen_manifest.json` / `.csv` — 全30画面とアプリのルート/状態の対応
4. `reference/browser_content/*.png` — iOSの架空ステータスバー・ホームインジケータを除いた**実装比較用**の画像 (390×769)
5. `reference/screens/*.png` — 元の**全画面**イメージ (390×844)
6. `assets/*.svg` — 元のデザインで使った猫と漫画サムネイルの**単体**ベクター素材
7. `reference/svgs/*.svg` — 位置・角丸・ベクター線の参照用。完成画面をこのSVGで実装しない
8. `preview.html` — ギャラリー（ブラウザで開いて比較、UI実装ではない）
9. `tools/visual_diff.py` — PNG差分画像と誤差メトリクスを生成する補助スクリプト

## UIの優先ソース

- 見た目の決定事項: このパッケージ（現行モノクロ／ブラッシュアップ版）を優先。
- API契約・認証・セキュリティ・保存期限・冪等性: 既存リポジトリのコードと API / OPERATIONS の内容を優先。
- この包みの30画面は **4つの基本ルート** と **状態/モーダルの差分**。30個の独立ルートを作らない。

## 最低限の確認

- 幅390pxでホーム／入力／カレンダー／漫画詳細／生成中の画面をスクショ比較する。
- 幅320px・430pxでも文字とCTAがはみ出さない。
- 主CTAを通常は下部ナビの上に置き、重なりとセーフエリアを実機で確認。
- タブは「ホーム／＋／カレンダー」で、選択中だけアイコンの**下**にラベル。
- 選択中タブはセグメント型、**内側の角が直線**。中央選択時も直線境界。
- 下書き保存は入力ヘッダーの右上、削除は漫画詳細の「…」メニュー。
- 文字や押せる操作を画像の一部として実装しない。

## 大事な注意

PNGには元デザインのモックとして `9:41` やiPhoneホームインジケータが描かれています。**実際のPWAでOSステータスバーやホームインジケータを偽装表示しないでください。** 通常のWebコンテンツ部分の比較には `reference/browser_content/` を使います。

参考画像はデザイン案であり、現行APIの実装済み画面のスクリーンショットではありません。生成中の画面などは実際のステータスに結びつけてください。
